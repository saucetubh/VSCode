# A Repository of Academic Programming Projects

## Synopsis

This repository serves as a centralized collection of source code and programming exercises completed as part of my computer science curriculum. The primary objective is to document my academic progress and practical application of learned concepts.

## Repository Structure

The content is organized hierarchically by programming language and subject matter. Each top-level directory corresponds to a specific language or technological domain.

## Core Technologies

This repository includes practical implementations in the following languages:

* **Hardware Description:** Verilog
* **Object-Oriented:** Java
* **Procedural:** C, C++
* **Logic:** Prolog

## Disclaimer

The code contained within this repository is for educational and demonstrative purposes. It reflects my understanding of the material at the time of its creation and may not represent production-quality software.

## Usage and Compilation

To execute any of the projects, the relevant compiler or runtime environment must be installed.

**Example Compilation:**

1.  **C:**
    ```bash
    gcc -o output_file source_file.c
    ./output_file
    ```

2.  **Verilog:**
    ```bash
    iverilog -o output_file source_file.v
    ./output_file
    ```
